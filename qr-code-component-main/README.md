### What I learned

I learned to use the universal reset and set box-sizing on border-box. Border-box is to change the standard content-box of browsers and margin and padding on 0 to start with fresh elements, having no margin and no padding, so more control for me. 

```css
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

Flexbox, in the beginning I realy had problems how to get the card in the middle of the screen, I tried it with margin, but that didnt worked good, I forgot how to use flexbox, so I asked for help, and now I now how to use it, very easy!

```css

.card {
  display: flex;
  align-items: center;
  justify-content: center;
}
